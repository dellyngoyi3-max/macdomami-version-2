Chevalets & QR Codes de table

Générez et imprimez les fiches QR code à disposer sur les tables de votre restaurant à Kinshasa.

Configuration des chevalets

Chaque QR code contient le lien exact vers votre menu avec le numéro de table intégré.

Synchronisation 100 % automatique :
Le QR code ouvre directement votre site web. Quand vous changez un prix, activez une formule ou modifiez un plat dans js/data.js, le nouveau menu s'affiche instantanément sur le téléphone du client. Vous n'avez jamais besoin de réimprimer les chevalets quand la carte évolue !

Note pour tester avec votre téléphone : L'aperçu actuel est dans votre espace de travail privé. Pour que votre téléphone (ou celui d'un client) puisse scanner et ouvrir le menu, le site doit être publié sur GitHub Pages (ou votre nom de domaine). Une fois publié, indiquez votre adresse publique ci-dessous (ex : https://votre-compte.github.io/macdo-mami/menu.html).
